Independent finance project · Financial Analysis | Financial Modeling | Forecasting | Data Visualization

Aurelia – Financial Analysis& Interactive Dashboard

A structured review of a fictional e-commerce and cloud services company, covering historical financial performance for FY2021–FY2025 and forecasts for FY2026E–FY2028E.

Independent portfolio project · Fictional company · Illustrative figures

01 — Context

A fictional business,
an analytical exercise.

Aurelia is a fictional e-commerce and cloud services company created for an independent financial analysis project. The work examines revenue growth, profitability, operating performance, financial trends and relationships between business segments.

02 — The Problem

Finding the story
in financial statements.

Financial statements contain extensive information, which can make it difficult to identify meaningful trends and understand overall performance. The challenge was to organize the data into a structured model and make the analysis easier to explore.

03 — The Mission

Structure the analysis;
clarify the view.

The goal was to assess historical performance, review key indicators and develop forward-looking projections, then present selected findings in an interactive dashboard.

04 — My Approach

From organized data
to clearer insight.

  1. 01Organized historical financial data.
  2. 02Built structured financial statements in Excel.
  3. 03Analyzed revenue growth and profitability.
  4. 04Calculated and reviewed financial indicators.
  5. 05Examined business segment performance.
  6. 06Developed forecasts for FY2026E–FY2028E.
  7. 07Created visual representations of financial results.
05 — Project Scope

Historical analysis covers FY2021–FY2025, with forecasts for FY2026E–FY2028E. The workbook is available as an official PDF export alongside a separate interactive HTML dashboard.

06 — Tools & Technologies

Tools used
in the work.

Microsoft Excel

Financial modeling, calculations, financial statements and forecasting.

HTML, CSS & JavaScript

Interactive financial dashboard and data visualization.

07 — Key Learning

This project strengthened my financial statement analysis, modeling and forecasting, performance evaluation, data organization and interpretation, and visualization skills.
